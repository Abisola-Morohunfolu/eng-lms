# Week 9: Cost and Architecture

## Goals

- Learn how cloud architecture choices affect spend.
- Practice cost estimation and architectural tradeoff review.
- Build the habit of evaluating reliability, security, performance, and cost together.

## Core resources

- [AWS Well-Architected Framework](https://docs.aws.amazon.com/wellarchitected/latest/framework/welcome.html)
- [AWS Pricing Calculator: Getting Started](https://docs.aws.amazon.com/pricing-calculator/latest/userguide/getting-started.html)
- [Google Cloud Well-Architected: Cost Optimization](https://cloud.google.com/architecture/framework/cost-optimization)
- [FinOps Framework Overview](https://www.finops.org/framework/)

## Exercises

1. Estimate the monthly cost of a toy application with:
   - one frontend
   - one API
   - one database
   - object storage
2. Write down five cost levers, such as rightsizing, storage class choice, autoscaling, shutdown schedules, or managed-service selection.
3. Review one architecture against the Well-Architected pillars and note the main tradeoffs.
4. Explain why "cheap now" and "cost-effective over time" are not always the same thing.

## Deliverable

- A simple cost estimate
- A one-page architecture review

## Exit check

You are ready for week 10 if you can explain at least three architectural tradeoffs without reducing the discussion to cost alone.
