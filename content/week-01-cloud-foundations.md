# Week 1: Cloud Foundations

## Goals

- Understand what cloud computing is and what it is not.
- Learn `IaaS`, `PaaS`, `SaaS`, regions, availability zones, elasticity, and shared responsibility.
- Build a basic mental model before touching services.

## Core resources

- [NIST Definition of Cloud Computing](https://www.nist.gov/publications/nist-definition-cloud-computing)
- [Overview of Amazon Web Services](https://docs.aws.amazon.com/whitepapers/latest/aws-overview/introduction.html)
- [AWS Global Infrastructure](https://docs.aws.amazon.com/whitepapers/latest/aws-overview/global-infrastructure.html)
- [AWS Shared Responsibility Model](https://docs.aws.amazon.com/wellarchitected/latest/security-pillar/shared-responsibility.html)

## Exercises

1. Write a one-page summary explaining `IaaS`, `PaaS`, and `SaaS` in your own words.
2. Draw a simple diagram showing one region with at least two availability zones.
3. For a virtual machine, an object-storage bucket, and a managed database, list what the cloud provider manages and what you manage.
4. Explain the difference between elasticity and scalability with one real example each.

## Deliverable

- One page of notes
- One diagram
- A glossary with at least 10 terms

## Exit check

You are ready for week 2 if you can explain why a workload might use multiple availability zones and what "security of the cloud vs security in the cloud" means.
